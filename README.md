# Reduce AI-Slop

去除文本中的AI生成痕迹，使文字听起来更自然、更有人味。

## 简介

Reduce AI-Slop 是一个专门用于去除AI写作痕迹的 Skill。当用户要求"去AI味""去除AI痕迹""让文字更像人写的""人性化这段文字""去机器味""让文章自然一点""reduce ai slop"时触发。

支持网文小说、学术论文、散文随笔、新媒体文章、商业文案、诗歌等多种文体的差异化处理。

## 核心特性

- **基于原文修改**：所有改动基于原文，禁止捏造事实、数据或案例
- **多文体支持**：自动识别6种文体并应用对应策略
- **审计-修订循环**：内置质量检查机制，不达标自动打回修改
- **精简输出**：仅返回修改后的文本，不附加审计报告等无关信息

## 使用方法

1. 将本 Skill 导入 CodeBuddy
2. 输入需要去AI味的文本
3. 可选指定文章类型和输出方式
4. 获得去AI味后的自然文本

## 工作流程

```
输入文本 → 识别文体 → 第一轮改写 → 审计扫描 → 达标？→ 输出
                                      ↓ 否
                                 修订处理 → 再次审计（最多3轮）
```

## 核心铁律

1. 基于原文修改，禁止捏造
2. 不得删除原文关键信息
3. 不得改变原文核心观点
4. 仅做语言风格层面的调整

## 支持的文体

| 文体 | 核心策略 |
|:---|:---|
| 网文小说 | 展示而非告知、破坏完美节奏 |
| 学术论文 | 主动语态优先、增加研究过程细节 |
| 散文随笔 | 允许跑题、具体怪异细节、留白 |
| 新媒体文章 | 减少格式装饰、加入争议性观点 |
| 商业文案 | 用场景替代形容词、加入具体数字 |
| 诗歌 | 意象陌生化、打破规整、口语入诗 |

## 审计维度

从7个维度评估去AI味效果，满分100分：

1. AI词汇检测（15%）
2. 结构模式检测（15%）
3. 语法与句式检测（15%）
4. 内容与归因检测（15%）
5. 情感与细节检测（15%）
6. 文体适配检测（15%）
7. 节奏与流畅度检测（10%）

通过标准：85分以上
