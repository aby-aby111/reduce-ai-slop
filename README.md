# Reduce AI-Slop 写作skill

去除文本中的AI生成痕迹（AI slop），使文字听起来更自然、更有人味。

## 简介

当用户要求"去AI味""去除AI痕迹""让文字更像人写的""人性化这段文字""去机器味""让文章自然一点""reduce ai slop"或类似的表达时触发此技能。

支持网文小说、学术论文、散文随笔、新媒体文章、商业文案、诗歌等多种文体。内置审计-修订循环机制，确保输出质量达标。

## 核心特性

- **基于原文修改**：所有修改基于原文，不捏造事实、数据、案例
- **多文体支持**：网文小说、学术论文、散文随笔、新媒体文章、商业文案、诗歌
- **双模式处理**：快速模式（默认，节省60%时间）和完整模式（高精度）
- **精简输出**：仅输出修改后的文本，不附加审计报告或修订记录
- **审计-修订循环**：内部质量检查确保去AI味效果

## 使用方法

### 基础用法

直接在对话中输入需要去AI味的文本：

```
帮我去AI味：
随着人工智能技术的不断发展，其在各个领域的应用日益广泛，为人类社会带来了前所未有的变革。
```

### 指定文体

如果知道文章类型，可以告诉助手：

```
这是一篇学术论文，帮我去AI味：
[文本内容]
```

支持的文体：网文小说、学术论文、散文随笔、新媒体文章、商业文案、诗歌。

### 指定输出方式

**对话输出**（默认）：直接在对话中返回结果，适合快速查看和多轮讨论。

**文件输出**：生成 `.md` 文件保存到工作区，适合文本较长或需要保存的情况。文件名格式：`去AI味_[主题]_[日期].md`。

### 调整处理模式

| 模式 | 用户指令 | 说明 |
|:---|:---|:---|
| 快速模式 | 默认（无特殊要求） | 一次性改写 + 3维度审计 + P0/P1修订，处理速度最快 |
| 完整模式 | "深度""彻底""高精度""完整" | 逐轮改写 + 7维度全检 + 全优先级修订，精度最高 |
| 轻度模式 | "轻度""快速""简单" | 仅做轻微调整，跳过审计 |

### 调整修改强度

- **轻度**：仅删除明显AI词汇，保留原文结构
- **中度**（默认）：删除AI词汇 + 打破公式结构 + 变化节奏
- **重度**：深度改写，增加个人风格、情感细节、逻辑跳跃

### 针对特定问题

```
帮我去AI味，重点处理：
1. 删除所有"随着...的发展"开头
2. 打破三段式结构
3. 增加具体的时间锚点

[文本内容]
```

## 用户使用流程

### 第一步：接收用户需求

用户输入通常包含以下信息：
- **待处理文本**（必需）：需要去AI味的原文
- **文章类型**（可选）：网文小说、学术论文、散文随笔、新媒体文章、商业文案、诗歌等。如未指定，自动识别
- **输出方式**（可选）：
  - **对话输出**（默认）：直接在对话中返回结果
  - **文件输出**：生成文件保存到工作区
- **特殊要求**（可选）：保留原文结构、仅轻度修改、针对某类AI痕迹重点处理等

### 第二步：确认输出方式

**如果用户未指定输出方式，默认使用对话输出。**

**对话输出场景：**
- 文本较短（<2000字）
- 用户需要快速查看结果
- 用户需要讨论修改细节
- 用户需要多轮迭代调整

**文件输出场景：**
- 文本较长（≥2000字）
- 用户需要保存结果
- 用户需要交付最终版本
- 用户指定了文件名或格式要求

**文件输出规范：**
- 默认保存为 `.md` 格式
- 文件名格式：`去AI味_[原文标题或主题]_[日期].md`
- 如用户指定文件名，按用户要求命名
- 文件内容仅包含修改后的文本，不包含审计报告或修订记录

### 第三步：执行去AI味流程

**快速模式（默认）：**

```
输入文本
    ↓
识别文体类型（用户指定或自动判断）
    ↓
一次性改写（基于文体策略 + 通用AI模式 + 快速检查清单）
    ↓
快速审计（3维度抽样检查）
    ↓
得分 ≥ 48？
    ↓ 是
输出最终文本
    ↓ 否
快速修订（仅处理P0/P1问题）
    ↓
再次快速审计（最多1轮）
    ↓
输出最终文本
```

**快速模式说明：**
- 一次性改写：直接应用所有策略，不逐轮迭代
- 快速审计：仅检查最关键的3个维度（AI词汇、结构模式、文体适配）
- 快速修订：仅处理致命和严重问题（P0/P1）
- 最多1轮修订，大幅缩短处理时间

**完整模式（用户要求深度处理时启用）：**

```
输入文本
    ↓
识别文体类型
    ↓
第一轮改写
    ↓
完整审计（7维度）
    ↓
得分 ≥ 85？
    ↓ 是
输出最终文本
    ↓ 否
完整修订（处理所有优先级问题）
    ↓
再次完整审计（最多3轮）
    ↓
输出最终文本
```

**完整模式说明：**
- 逐轮改写：每轮聚焦不同策略
- 完整审计：7个维度全面检查
- 完整修订：处理所有优先级问题（P0/P1/P2/P3）
- 最多3轮修订，确保高质量

**模式选择规则：**

| 用户指令关键词 | 启用模式 |
|:---|:---|
| 无特殊要求（默认） | 快速模式 |
| "深度""彻底""高精度""完整""严格" | 完整模式 |
| "轻度""快速""简单""粗略" | 轻度模式（跳过审计） |

### 第四步：输出结果

**仅输出修改后的文本，不输出审计报告、修订记录、评分等无关信息。**

**对话输出格式：**

```

```

**文件输出格式：**

```markdown
（仅包含修改后的完整文本，不附加审计报告、修订记录等）
```

### 第五步：用户反馈与迭代

输出后询问用户是否需要调整：
- "是否需要针对某处进一步修改？"
- "是否需要保存为文件？"

## 核心铁律

**基于原文修改，禁止捏造。**

- 所有修改必须基于原文内容，不得添加原文不存在的事实、数据、案例或观点
- 不得删除原文的关键信息
- 不得改变原文的核心观点
- 仅做语言风格层面的调整：删除AI痕迹词汇、打破公式结构、变化节奏、增加自然感
- 如果原文存在数据空洞或模糊归因，直接删除相关表述，不得编造数据补充

## 支持的文体

| 文体 | 常见AI痕迹 | 去AI味策略 |
|:---|:---|:---|

| **新媒体文章** | 震惊体开头、三段式法则、金句结尾 | 自然开头、打破三段式、用事实代替金句 |

| **诗歌** | 意象堆砌、过度象征、完美押韵 | 减少意象密度、具体场景、允许不完美 |

## 审计体系

### 快速审计（默认模式）

仅检查最关键的3个维度，满分60分：

| 维度 | 权重 | 检查重点 | 快速检查方法 |
|:---|:---|:---|:---|
| A：AI词汇检测 | 20% | 高频AI词、力量词汇、过渡词滥用 | 扫描前10个高频AI词是否出现 |
| B：结构模式检测 | 20% | 三段式、三明治结构、八股文结尾 | 检查开头和结尾是否有公式化结构 |
| F：文体适配检测 | 20% | 按文体专门检查 | 对照genre_guide.md快速核对 |

**快速通过标准：**
- **通过（≥48分/60分）：** 直接输出
- **建议微调（42-47分）：** 快速修订后输出
- **未通过（<42分）：** 快速修订（仅P0/P1）后再次检查

### 完整审计（深度模式）

从7个维度进行扫描，满分100分：

| 维度 | 权重 | 检查重点 |
|:---|:---|:---|
| A：AI词汇检测 | 15% | 高频AI词、力量词汇、过渡词滥用 |
| B：结构模式检测 | 15% | 三段式、三明治结构、八股文结尾、挑战与展望 |
| C：语法与句式检测 | 15% | 系动词回避、被动语态、破折号滥用、-ing结尾分析 |
| D：内容与归因检测 | 15% | 夸大意义、模糊归因、数据空洞、虚构逻辑链 |
| E：情感与细节检测 | 15% | 情绪刻度、时间感、感官细节、观点缺失 |
| F：文体适配检测 | 15% | 按文体专门检查（见genre_guide.md） |
| G：节奏与流畅度检测 | 10% | 句子长度、段落结尾、同义词循环、填充短语 |

**完整通过标准：**
- **优秀（85-100分）：** 通过，无需修订
- **良好（70-84分）：** 通过，但建议微调
- **不合格（低于70分）：** 打回修订

## 修订体系

### 快速修订（默认模式）

仅处理致命和严重问题：

| 优先级 | 问题类型 | 处理要求 |
|:---|:---|:---|
| P0（致命） | AI词汇、文体严重不适配 | 必须修改 |
| P1（严重） | 结构模式、虚构逻辑、数据空洞 | 必须修改 |

**快速修订策略：**
- AI词汇：直接替换或删除
- 结构模式：打破公式结构（改为两项/四项、删除八股结尾）
- 文体不适配：参照genre_guide.md核心策略快速调整

### 完整修订（深度模式）

根据审计报告中的问题清单，按优先级进行针对性修改：

| 优先级 | 问题类型 | 处理要求 |
|:---|:---|:---|
| P0（致命） | AI词汇、文体严重不适配 | 必须修改 |
| P1（严重） | 结构模式、虚构逻辑、数据空洞 | 必须修改 |
| P2（中等） | 语法问题、夸大意义、模糊归因 | 建议修改 |
| P3（轻微） | 节奏问题、填充短语 | 可选修改 |

### 标准修订方法速查

| 问题类型 | 修订策略 |
|:---|:---|
| AI词汇 | 替换为自然表达或直接删除 |
| 三段式法则 | 改为两项或四项，或打乱顺序 |
| 系动词回避 | 简化回"是""有" |
| 夸大意义 | 删除象征性表述，保留事实 |
| 模糊归因 | 补充具体来源或删除 |
| 数据空洞 | 直接删除，不得编造数据补充 |
| 虚构逻辑链 | 承认复杂性或删除因果 |
| 情绪刻度缺失 | 加入具体感受和场景（基于原文内容） |
| 时间感缺失 | 加入具体时间锚点（基于原文内容） |
| 感官细节缺失 | 加入五感体验（基于原文内容） |
| 被动语态泛滥 | 改为主动语态 |
| 破折号过度 | 改为逗号或句号 |
| 填充短语 | 直接删除 |
| 通用积极结论 | 替换为具体事实 |
| 文体不适配 | 参照genre_guide.md对应策略 |

## 常见问题

**Q：会改变原文意思吗？**
A：不会。核心铁律要求所有修改基于原文，不添加原文不存在的信息，不改变核心观点。

**Q：支持哪些文体？**
A：网文小说、学术论文、散文随笔、新媒体文章、商业文案、诗歌。自动识别或用户指定。

**Q：输出包含审计报告吗？**
A：不包含。仅输出修改后的文本，审计在内部完成。

**Q：修改强度可以调整吗？**
A：可以。支持轻度、中度（默认）、重度三档。

**Q：快速模式和完整模式有什么区别？**
A：快速模式（默认）使用3维度审计和P0/P1修订，处理速度快；完整模式使用7维度全检和全优先级修订，精度更高但耗时更长。日常去AI味推荐快速模式。

**Q：文本AI痕迹很重怎么办？**
A：使用完整模式（"深度处理"）或多轮迭代。重度修改强度也能处理更顽固的AI痕迹。
