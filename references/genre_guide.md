# 分文体去AI味策略指南

不同文体的AI痕迹表现不同，去AI味的方法也应有所区别。本指南按文体类型提供专门的识别策略和改写方法。

---

## 一、网文小说 / 短篇故事

### AI痕迹特征

**叙事层面：**
- 过度解释角色动机（"他这样做是因为……"）
- 情绪标签代替情绪展示（"她感到很伤心"vs展示她哭泣）
- 场景切换过于平滑，缺乏意外
- 对话过于"正确"，每个人说话都像受过良好教育
- 描写面面俱到，没有聚焦（环境描写像说明书）
- 巧合过于巧合，转折过于转折

**语言层面：**
- 形容词堆砌（"美丽的大眼睛""高大的身躯"）
- 副词滥用（"他冷冷地说""她温柔地笑"）
- 句式单一，缺乏口语化节奏
- 环境描写模板化（"阳光明媚的早晨""漆黑的夜晚"）

### 去AI味策略

**展示而非告知：**
- 删除所有情绪标签，改为动作和细节
- "他很愤怒" → "他把杯子摔在地上，碎片溅了一地"

**破坏完美节奏：**
- 在紧张场景中插入无关细节（角色注意到窗外的鸟）
- 让对话被打断、被误解、答非所问

**加入口语化表达：**
- 允许角色说半句话、重复、口吃
- 加入方言、口头禅、时代感词汇

**聚焦感官：**
- 不要描写整个房间，只写角色注意到的那一样东西
- 加入气味、温度、触感等被AI忽略的细节

**制造不完美：**
- 让情节有漏洞，让角色有缺点
- 允许故事走向出人意料的方向

### 网文特有技巧

- **卡点节奏：** 章末留悬念，但不要每次都"就在这时……"
- **爽点铺垫：** 打脸要有足够的憋屈铺垫，AI常铺垫不足
- **人设一致性：** 确保角色言行符合其身份背景，AI常让底层角色说出知识分子的话

## 二、学术论文

### AI痕迹特征

**结构层面：**
- 完美的"引言-文献综述-方法-结果-讨论-结论"结构
- 每段开头都是主题句，中间支撑，结尾过渡
- 过渡词密集（"此外""然而""因此"）
- 结论段总是"本文研究表明……"开头

**语言层面：**
- 被动语态泛滥（"数据被分析""结果被得出"）
- 名词化过度（"进行分析"vs"分析"）
- 空洞的强调（"具有重要意义""不可忽视"）
- 引用格式完美但内容空洞

**内容层面：**
- 文献综述像罗列清单，缺乏批判性整合
- 讨论部分总是"与已有研究一致"
- 缺乏具体的研究局限（总是"样本量有限"）

### 去AI味策略

**打破八股结构：**
- 允许引言中有个人研究动机（"我最初注意到这个现象是因为……"）
- 讨论部分可以承认矛盾和困惑
- 结论不必总结全文，可以提出新的问题

**主动语态优先：**
- "我们分析了数据"替代"数据被分析"
- "我们发现"替代"结果表明"

**具体化抽象概念：**
- "具有重要意义" → "在p<0.01水平上显著"
- "样本量有限" → "仅覆盖了东部沿海三座城市，中西部情况可能不同"

**增加批判性：**
- 文献综述要指出矛盾而非罗列
- 讨论部分要敢于说"这与预期不符"

**加入研究过程细节：**
- "前两次实验都失败了，第三次调整了温度参数后才得到稳定结果"
- "受访者中有一位退休教师的回答让我们重新思考了假设"

### 论文特有技巧

- **引用要具体：** 不要"有研究表明"，要"Smith(2019)通过对200名大学生的追踪调查发现"
- **数据要真实：** AI常编造数据，要核实或模糊化（"约七成"替代"78.3%"）
- **术语要准确：** AI可能用错学术术语，需专业人士把关

## 三、散文 / 随笔

### AI痕迹特征

**结构层面：**
- 开头宏大，中间空洞，结尾升华
- 三段式结构明显（"首先……其次……最后……"）
- 段落长度过于均匀

**语言层面：**
- 排比句过度使用
- 比喻堆砌但缺乏新意（"时间如流水""人生如梦"）
- 感叹号滥用
- 金句过多，每段都想被摘抄

**内容层面：**
- 感悟过于正确，缺乏矛盾
- 个人经历过于"典型"，缺乏特异性
- 情感表达过于直白，缺乏留白

### 去AI味策略

**允许跑题：**
- 散文可以从中途突然转向
- 允许想到哪写到哪，不必每段都扣题

**具体细节优先：**
- 不要写"母亲很爱我"，写"她总在粥里多放一颗红枣"
- 不要写"故乡很美"，写"村口那棵歪脖子槐树"

**留白与克制：**
- 删除所有"我明白了""我懂得了"
- 让情感通过细节自然流露，而非直接陈述

**打破排比：**
- 将排比句拆散，改为长短交错的自然句式
- 允许有瑕疵的句子存在

**加入不完美：**
- 承认困惑、矛盾、未解的问题
- 不要每篇文章都必须有结论

### 散文特有技巧

- **声音要独特：** 找到作者独特的语调和节奏，AI的散文听起来都一样
- **细节要怪异：** 最打动人的细节往往是那些"不该注意到的"（"父亲切菜时总把左手小指翘起来"）
- **结构要呼吸：** 长短段落交替，像呼吸一样有节奏

## 四、新媒体文章 / 公众号推文

### AI痕迹特征

**结构层面：**
- 小标题过多，每段都有加粗
- 总是"总-分-总"结构
- 结尾必有"总结"或"行动号召"

**语言层面：**
- 网络热词堆砌（"绝绝子""yyds""破防了"）
- 感叹号和emoji过度使用
- 短句过度，缺乏长句支撑
- "你知道吗""划重点"等引导语频繁

**内容层面：**
- 案例总是那几个（马云、马斯克、张一鸣）
- 观点过于安全，不敢得罪任何一方
- 数据引用模糊（"据统计""有研究显示"）

### 去AI味策略

**减少格式装饰：**
- 删除不必要的加粗和emoji
- 小标题不要每段都有

**热词要克制：**
- 最多用一两个网络用语，且要符合文章调性
- 不要用已经过时的热词

**加入争议性观点：**
- 新媒体需要态度，不要骑墙
- 可以明确说"我不认同这个观点"

**案例要新鲜：**
- 用最近一周的新闻，不要用三年前的案例
- 用身边的例子替代名人故事

**口语化但不过度：**
- 像对朋友说话，但不要用"宝子们""家人们"
- 允许有语病的流畅感

### 新媒体特有技巧

- **开头要抓人：** 用场景、冲突、反常识开头，不要用"随着……"
- **段落要短：** 手机阅读每段不超过3行，但要有长短变化
- **金句要克制：** 一篇文章最多2-3个值得划线的地方

## 五、商业文案 / 营销内容

### AI痕迹特征

**语言层面：**
- 形容词轰炸（"革命性的""颠覆性的""前所未有的"）
- 排比句推销（"更快速、更高效、更智能"）
- 空洞承诺（"改变你的生活""引领未来"）
- 技术参数罗列像说明书

**结构层面：**
- 总是"痛点-解决方案-优势-行动号召"
- 每个卖点都配一个 bullet point
- 结尾总是"立即行动"或"联系我们"

### 去AI味策略

**用场景替代形容词：**
- "高效办公" → "早上9点的会议，你8:55才收到资料，5分钟后你已经整理好了要点"

**加入具体数字：**
- "大幅提升" → "处理时间从3小时缩短到20分钟"
- "深受好评" → "上线30天，App Store评分4.8，评论里提到最多的是……"

**承认限制：**
- "目前仅支持iOS系统，安卓版本正在开发"
- 真诚的限制比虚假的完美更有说服力

**用户语言替代营销语言：**
- 用真实用户的评价替代自夸
- "一位用了三个月的用户说：'……'"

### 文案特有技巧

- **卖点要单一：** 不要试图一次说10个好处，聚焦最强的一个
- **CTA要具体：** "免费试用14天"比"立即行动"好
- **故事要真实：** 用真实客户案例，不要用"小明"

## 六、诗歌

### AI痕迹特征

**语言层面：**
- 意象陈词滥调（"月亮代表思念""落叶象征离别"）
- 押韵生硬，为押韵而押韵
- 分行像散文断句，没有诗的节奏
- 情感表达直白，缺乏留白

**结构层面：**
- 过于规整（每节4行，每行字数相近）
- 结尾总是升华或点题

### 去AI味策略

**意象要陌生化：**
- "月亮" → "被啃了一口的银饼"
- 用通感（"蓝色的声音""苦涩的光"）

**打破规整：**
- 允许有的节长有的节短
- 允许断句在奇怪的地方

**留白：**
- 删除解释性的句子
- 让意象自己说话

**口语入诗：**
- 允许日常语言进入诗歌
- "我今天不想上班"也可以是诗

## 七、类型识别方法

当用户未明确指定文章类型时，通过以下特征自动识别：

| 特征 | 网文小说 | 学术论文 | 散文随笔 | 新媒体 | 商业文案 | 诗歌 |
|:---|:---|:---|:---|:---|:---|:---|
| **人称** | 第三人称为主 | 第一人称复数/被动 | 第一人称 | 第二人称/混合 | 第二人称 | 混合 |
| **段落长度** | 短，对话多 | 长，论证型 | 中等，有变化 | 很短，手机友好 | 短，bullet多 | 极短，分行 |
| **连接词密度** | 低 | 极高 | 中等 | 中等 | 低 | 无 |
| **情感表达** | 展示+标签 | 克制，客观 | 直接+含蓄 | 外放 | 积极，推销 | 意象化 |
| **结构** | 情节驱动 | IMRAD | 松散，联想 | 总-分-总 | 痛点-方案 | 自由 |
| **典型开头** | 场景/对话 | "随着……" | 场景/感悟 | 冲突/反常识 | 痛点/数据 | 意象 |

## 八、通用检查清单（按文体）

### 网文小说检查
- [ ] 对话是否自然？是否有人打断、答非所问？
- [ ] 情绪是否通过动作展示而非标签告知？
- [ ] 是否有不必要的环境描写可以删除？
- [ ] 角色语言是否符合其身份背景？
- [ ] 情节是否有意外和漏洞？

### 学术论文检查
- [ ] 被动语态是否过多？
- [ ] 是否有"具有重要意义"等空洞表述？
- [ ] 引用是否具体？
- [ ] 讨论部分是否有批判性？
- [ ] 是否承认研究局限？

### 散文随笔检查
- [ ] 是否有"我明白了"等直白感悟？
- [ ] 细节是否具体且怪异？
- [ ] 是否有留白？
- [ ] 结构是否允许跑题？
- [ ] 结尾是否必须总结？

### 新媒体检查
- [ ] 开头是否抓人？
- [ ] 小标题和加粗是否过多？
- [ ] 案例是否新鲜？
- [ ] 观点是否有态度？
- [ ] 段落长度是否适合手机阅读？

### 商业文案检查
- [ ] 形容词是否过多？
- [ ] 是否有具体数字？
- [ ] 是否承认产品限制？
- [ ] CTA是否具体？
- [ ] 卖点是否聚焦？

### 诗歌检查
- [ ] 意象是否陈词滥调？
- [ ] 押韵是否生硬？
- [ ] 分行是否有节奏？
- [ ] 是否有留白？
- [ ] 是否允许口语入诗？
